## 2. Алгоритмы и примеры

### Линейное контрастирование (Linear Contrast Stretching)

Линейное контрастирование — это метод улучшения изображений путем растяжения диапазона
интенсивности (яркости). Цель алгоритма — масштабировать значения яркости пикселей так, чтобы самый
темный
пиксель стал абсолютно черным (0), а самый светлый — абсолютно белым (255).

**Реализация:**
В данной лабораторной работе алгоритм реализован независимо для каждого цветового канала (R, G, B),
что позволяет увеличить контраст не только по яркости, но и по цвету.

1. Происходит проход по всему изображению для нахождения минимального ($min$)
   и максимального ($max$) значения яркости для каждого канала.
2. **Нормализация:** К каждому пикселю применяется формула линейного преобразования:
   $$f'(x, y) = \left( \frac{f(x, y) - min}{max - min} \right) \cdot 255$$
   Где:

* $f(x, y)$ — исходное значение пикселя.
* $f'(x, y)$ — новое значение.
* $255$ — максимальное возможное значение в 8-битном канале.

**Физический смысл формулы:**
Дробь $\frac{f(x, y) - min}{max - min}$ переводит значение пикселя в диапазон от 0.0 до 1.0. Затем
умножение на 255 масштабирует его обратно в целочисленный диапазон байта. Если исходный пиксель был
равен $min$, он станет 0. Если был равен $max$, станет 255. Все промежуточные значения растянутся
линейно.

### Эквализация гистограммы в пространстве RGB

Эквализация гистограммы — это нелинейный метод повышения контраста. В отличие от
линейного растяжения, который просто «раздвигает» график, эквализация стремится изменить
распределение яркостей так, чтобы гистограмма стала **равномерной**. Это значит, что каждый уровень
яркости (от 0 до 255) должен встречаться на изображении примерно одинаковое количество раз. Это
позволяет максимально детально проявить информацию на изображении.

**Реализация:**
В данном методе обработка ведется для каждого канала (Red, Green, Blue) отдельно.

1. **Построение гистограммы ($H$):** Подсчитывается количество пикселей для каждого значения
   яркости $i$ (от 0 до 255).
2. **Вычисление CDF - Cumulative Distribution Function:**
   Строится кумулятивная гистограмма. Для каждого уровня яркости $i$ значение $CDF(i)$
   равно сумме всех пикселей с яркостью меньше или равной $i$:
   $$CDF(i) = \sum_{j=0}^{i} H(j)$$
   CDF показывает, какой процент пикселей изображения темнее текущего уровня.
3. **Создание таблицы поиска LUT - Look-Up Table:**
   Значения CDF нормализуются, чтобы получить новые значения яркости пикселей:
   $$h(v) = \text{round}\left( \frac{CDF(v) - CDF_{min}}{(M \times N) - CDF_{min}} \times 255 \right)$$
   Где $M \times N$ — общее количество пикселей.
4. **Преобразование:** Значение каждого пикселя заменяется на значение из таблицы LUT.

### Эквализация гистограммы в пространстве HSV

Чтобы избежать искажения цветов, свойственного RGB-эквализации, изображение переводится в цветовое
пространство, где яркость отделена от хроматической (цветовой) составляющей. Пространство HSV
идеально подходит для этого, так как канал **V (Value)** отвечает только за
яркость.

**Реализация:**

1. **Конвертация:** Каждый пиксель исходного изображения преобразуется из модели RGB в модель HSV.

* $H$ (Тон) — оттенок цвета (0–360°).
* $S$ (Насыщенность) — «чистота» цвета.
* $V$ (Значение/Яркость) — интенсивность света.

2. **Обработка канала V:** Алгоритм эквализации (построение гистограммы $\rightarrow$ вычисление
   CDF $\rightarrow$ создание LUT), описанный в предыдущем пункте, применяется **только** к
   компоненте $V$. Компоненты $H$ и $S$ остаются неизменными.
3. **Обратная конвертация:** Полученные значения ($H$, $S$, $V_{new}$) преобразуются обратно в
   модель RGB для отображения на экране.

**Преимущество:**
Этот метод усиливает локальный контраст и прорабатывает детали в тенях и светах, сохраняя исходные
цвета объектов. Например, красное яблоко останется красным, станет лишь более выразительным, в то
время как в RGB оно могло бы стать фиолетовым или оранжевым.

*Описание:* Темная фотография с наличием полезных деталей в тенях (например, человек в темной
комнате).

### Увеличение резкости 

Резкость изображения определяется скоростью изменения яркости на границах объектов. Чем резче
переход от темного к светлому, тем более четким кажется изображение. Повышение резкости
осуществляется методом **пространственной фильтрации (свертки)** с использованием матрицы (ядра),
которая является фильтром верхних частот.

В работе используется ядро свертки (Kernel) размером $3 \times 3$, представляющее собой дискретный
Лапласиан с усилением центрального элемента:

$$
K = \begin{bmatrix}
0 & -1 & 0 \\
-1 & 5 & -1 \\
0 & -1 & 0
\end{bmatrix}
$$

**Как работает свертка:**
Окно $3 \times 3$ скользит по каждому пикселю изображения. Новое значение центрального пикселя
вычисляется как сумма произведений соседних пикселей на соответствующие коэффициенты матрицы:
$$NewPixel = 5 \cdot Center - (Top + Bottom + Left + Right)$$

**Интерпретация:**

1. **На однородных участках:** Если все пиксели имеют одинаковый цвет (например, 100), то
   результат: $5 \cdot 100 - (100+100+100+100) = 500 - 400 = 100$. Цвет не меняется.
2. **На границах:** Если центральный пиксель яркий, а соседи темные (или наоборот), разница между
   ними многократно усиливается. Это создает эффект «микроконтраста» вокруг контуров, что
   глаз воспринимает как повышение резкости.
